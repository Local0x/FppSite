Что такое F++

Язык сделан не для Enterprise, а для быстрых рабочих тулз: окно, скрипт, конфиг, файловая утилита, сетевой тест, панель управления, прототип.

Ядро

Переменные, условия, циклы, функции, массивы, мапы, строки, try/catch, throw, assert.

GUI

Окна, кнопки, поля ввода, label'ы, изображения, меню, иконки, диалоги выбора файлов.

Сеть

HTTP GET/POST, JSON, form-data, скачивание файлов, TCP-клиент и TCP-сервер.

ОС

Команды системы, окружение, пути, буфер обмена, открытие файлов и аргументы запуска.

Плагины

Новые библиотеки добавляются через Python-плагины и подключаются через use().

IDE

Тёмный редактор, подсветка, автокомплит, авто-скобки, консоль и запуск кода.

Плагины

Как расширять F++ своими библиотеками.

Минимальный плагин

fpp_plugin_demo.py
import fpp_ext


def load_demo_library(interp, env):
    def demo_hello(args):
        return "hello from plugin"

    env.define("demo_hello", demo_hello)


fpp_ext.register_library("demo", load_demo_library)

Использование

script.fpp
use("demo");

print demo_hello();

Что получает плагин

interp

Доступ к интерпретатору, вызову функций, состоянию.

env

Окружение, куда регистрируются функции и значения.

args

Массив аргументов, переданных из F++.

return

Возвращаемое значение становится значением F++.

Автозагрузка

Если файл называется как fpp_plugin_*.py, загрузчик подхватит его автоматически.

структура
fpp/
├── fpp_ext.py
└── fpp_plugin_demo.py

Пример с состоянием

fpp_plugin_counter.py
import fpp_ext


def load_counter_library(interp, env):
    state = {
        "value": 0
    }

    def counter_inc(args):
        state["value"] += 1
        return state["value"]

    def counter_get(args):
        return state["value"]

    env.define("counter_inc", counter_inc)
    env.define("counter_get", counter_get)


fpp_ext.register_library("counter", load_counter_library)
script.fpp
use("counter");

counter_inc();
counter_inc();

print counter_get();

Ошибки в плагинах

    def demo_fail(args):

fpp_ext.register_library("demo", load_demo_library)

    demo_fail();
} catch(e) {
    print e;
}

Callback из плагина

fpp_plugin_callback.py
import fpp
import fpp_ext


def load_callback_library(interp, env):
    def run_callback(args):
        if len(args) != 1:
            raise fpp.FppError("run_callback() expects 1 argument")

        callback = args[0]

        if not isinstance(callback, fpp.Function) and not callable(callback):
            raise fpp.FppError("run_callback() expects a function")

        interp.call_function(callback, [])
        return None

    env.define("run_callback", run_callback)


fpp_ext.register_library("callback", load_callback_library)
script.fpp
use("callback");

run_callback(func() {
    print "called from plugin";
});

Чеклист плагина

1. Файл

Назови файл fpp_plugin_name.py.

2. Загрузчик

Сделай функцию load_name_library(interp, env).

3. Регистрация

Вызови fpp_ext.register_library("name", loader).

4. Функции

Каждая функция принимает args и возвращает значение F++.
